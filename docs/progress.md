## سجل الجلسات

### الجلسة 1 · 2026-09-08

**الوحدة:** 0

**ما بُني:**

- **الهيكل.** مونوريبو pnpm workspaces مع turbo، وTypeScript strict مع `noUncheckedIndexedAccess` و`exactOptionalPropertyTypes`. `packages/db` مكتملة، وبقية الحزم والتطبيقات هياكل فارغة. `apps/console` مؤجل للوحدة 8.
- **أربعة ترحيلات** بـ`up` و`down` لكل واحدة، ومشغّل في `packages/db/src/migrator.ts` مع سجل بالبصمة في `nx_meta.schema_migrations` يرفض أي تعديل على ترحيل مطبّق. الأمر `migrate verify` يطبّق ثم يتراجع ثم يطبّق مجدداً ويقارن لقطتَي المخطط.
  - `0001` الأدوار الثلاثة وschema `app`
  - `0002` جداول `tenants` و`entities` و`attestations`
  - `0003` RLS والصلاحيات
  - `0004` عدم قابلية الإفادات للتعديل
- **الأدوار.** `nx_migrator` مالك ويشغّل الترحيلات فقط، `nx_app` بلا ملكية وبلا `BYPASSRLS`، `nx_retention` الدور الوحيد الحامل لـ`DELETE` على `attestations`. الأدوار تُنشأ بلا كلمة مرور، والمشغّل يضبطها من البيئة، فلا اعتماد في أي ملف ترحيل.
- **العزل.** `ENABLE` و`FORCE ROW LEVEL SECURITY` على الجداول الثلاثة، سياسة بـ`USING` و`WITH CHECK` معاً، ودالة `app.current_tenant()` تُرجع NULL حين لا يُضبط السياق فيصبح الفشل مغلقاً. `withTenant()` في `packages/db/src/client.ts` هو مسار الوصول الوحيد، ويضبط `app.tenant_id` بـ`is_local` فلا يتسرب السياق عبر تجميع الاتصالات.
- **الحارسان 01 و02** يمران، ويتصلان بدور التطبيق لا بدور المالك. الحارس 01 يثبت الطبقتين منفصلتين: الصلاحيات ترفض بدور التطبيق، والمحفزات ترفض بدور المالك الذي يملك الصلاحية أصلاً. الحارس 02 يعدّد من فهرس قاعدة البيانات كل جدول يحمل `tenant_id` بدل قائمة ثابتة، فأي جدول يُضاف لاحقاً بلا RLS يُفشله تلقائياً.
- **اختبار انحراف** يقارن تعريفات Drizzle بفهرس القاعدة المُرحَّلة.
- **خط CI** بست وظائف: lint، typecheck، style، migrate، test، guards. الحراس وظيفة مستقلة باسمها.
- **الاختبارات على بوستجرس 16 حقيقي** عبر Testcontainers، بحاوية واحدة لكل تشغيل، وقاعدة مستقلة لكل ملف اختبار مستنسخة من قاعدة قالب مُرحَّلة. لا مسار بديل ولا متغير بيئة يتجاوزها.

**ما تبقى:**

- الوحدة 1: `entity_identifiers` بهاش HMAC ومشفّر، فهرس `uq_ident`، عرض `entity_profile`، `freshness_policy`، ومستودعات الإدراج والقراءة.
- الحراس 03 إلى 08 ملفات بـ`it.todo` تُفعَّل بوحداتها.
- `apps/console` بالوحدة 8، و`apps/api` بالوحدة 7.
- المستودع ليس مستودع git بعد. شغّل `git init` قبل أول التزام.

**عوائق:** لا شيء يعوق الوحدة 1. تشغيل الاختبارات يتطلب Docker مشغّلاً على الجهاز، وهو أثر مباشر للبند 11.

**قرارات معمارية:**

- **ADR-009** الترحيلات SQL خام، وDrizzle طبقة استعلام لا مولّد.
- **ADR-010** عدم قابلية الإفادات للتعديل بمحفزات ترفع أخطاء، لا بـ`RULE ... DO INSTEAD NOTHING`.
- **ADR-011** لا `BYPASSRLS` في النظام، وإنشاء المستأجر يمر بنفس مسار كل شيء آخر.

**تصحيح مطلوب في المستندات:**

`docs/02-schema.md` القسم 3 يعرض قاعدة منع تحديث لا تكفي وتخالف الحارس 01. التنفيذ اتبع `CLAUDE.md` كما هو منصوص، وADR-010 يوثّق السبب. يُحدَّث المستند عند أول تعديل عليه.

**أوامر التشغيل:**

```
pnpm install
pnpm run migrate:verify   # يطبّق ويتراجع ويطبّق مجدداً في حاوية
pnpm run guards           # حراس المعمارية وحدهم
pnpm run test             # كل الاختبارات
pnpm run lint && pnpm run typecheck && pnpm run style
```
